## 新加坡VPS测评该看什么：五个能自己动手验的指标

搜“新加坡VPS测评”的人最容易踩的坑，是把商家首页那张“CN2 优化”的图当成结论。真正决定体验的东西，商家不一定写，但你能自己测。

**第一，回程路由，不是去程。** 去程很多商家都能挂一段 CN2 上去，回程才决定你晚上八点访问顺不顺。要一个测试 IP，在本机 `tracert`（Windows）或 `mtr -r -c 100`（Linux）跑三网回程，逐跳看经过的 AS 号。看到 AS4809 是电信 CN2，AS9929 是联通精品网，AS4837 和 AS10099 是联通普通骨干与国际出口，AS58453 是移动 CMI，CMIN2 走的是移动精品回程。

**第二，晚高峰 19:00–23:00 的实测数据。** 白天单线程跑满带宽不说明什么，这个时段国际出口会被视频和下载流量挤满。要看的是这个时间段里丢包率和速率掉到什么程度。商家给的测速截图如果是工作日上午跑的，参考价值有限。

**第三，单核性能和磁盘 I/O。** 建站、跑数据库、开面板吃的是单核频率，不是核心数。一个 2 核高频的机器，实际体验可能比 4 核低频的还利索。磁盘要看 4K 随机读写，不看 dd 顺序读写那串漂亮数字。

**第四，IP 属性。** 是不是原生 IP、能不能解锁你要用的流媒体、建站会不会因为 IP 段历史被牵连。这一项商家基本不会主动说，得自己查 IP 归属库，再看流媒体解锁情况。

**第五，超额策略和防护。** 流量超了是断网、限速还是扣费，DDoS 清洗容量多少，这两项写在条款里而不是首页上。不限流量的机型不用操心第一条，但端口带宽会封顶，10M 就是 10M。

LightLayer 这套新加坡机型里，第一条能自己验，第二条得买完才有数据。这也是 24 小时或工单沟通窗口的价值所在。

## CN2、9929、CMIN2 分别是什么，LightLayer 占了几条

这三个名词经常被打包成“三网精品”一起卖，实际上它们分属三家运营商，各管一段。

**CN2（AS4809）** 是中国电信的高端骨干网，分 GT 和 GIA 两级，GIA 优先级最高、丢包最低。普通电信用户走的是 163 干线，晚高峰拥堵就发生在那条线上。

**AS9929** 是中国联通的精品网，定位相当于 CN2 GIA 之于电信。普通联通走 AS4837（10099）这条大路。

**CMIN2** 是中国移动的精品回程，对应普通 CMI（AS58453）。移动家宽晚高峰掉速，原因就是回程全挤在 CMI 上。

所谓“三网精品回程”，指的是电信走 CN2、联通走 9929、移动走 CMIN2，三条都到位。

拿这个标准去套 LightLayer 新加坡：电信是双程 CN2，移动是去程 CMIN2、回程走电信香港 CN2，这两条都算优化线路。联通是去程 AS4837 加 AS10099 直连、回程走联通香港 AS4837 回内地，属于直连，不是 9929 精品网。

这个区别对联通用户的实际影响没那么大，香港节点直连回内地，路径短、绕行少，延迟通常不会差。但如果你在别的测评里看到“LightLayer 三网全精品”这种说法，那是不准确的。它给的是电信双程 CN2、移动 CMIN2 加 CN2 回程、联通香港直连，三家的路径不同，速度表现也会有差异。
